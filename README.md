## Возможности

- Добавление проектов (название, ссылка, статус)
- Привязка навыков к проектам
- Просмотр списка проектов и подробной информации о каждом
- Обновление полей проекта: имя, описание, ссылка, статус
- Удаление проектов
- Получение информации о проекте по вводу его имени
- Отмена действий на шагах выбора через кнопку `Отмена 🚫`

## Структура проекта

```
.
├── main.py      # Telegram-бот
├── logic.py     # Класс DB_Manager для работы с SQLite
└── config.py    # Конфигурация (TOKEN, DATABASE)
```

## Требования

- Python 3
- `pytelegrambotapi` (пакет `telebot`)
- `sqlite3` (стандартная библиотека Python)

## Установка и настройка

1. Клонируйте репозиторий:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ИМЯ_ДИРЕКТОРИИ>
```

2. Создайте и активируйте виртуальное окружение (по желанию):

```bash
python -m venv venv
source venv/bin/activate      # Linux / macOS
venv\Scripts\activate         # Windows
```

3. Установите зависимости:

```bash
pip install pytelegrambotapi
```

4. В файле `config.py` определите:

- `TOKEN` — токен Telegram-бота
- `DATABASE` — путь к файлу базы данных SQLite

## Инициализация базы данных

Перед первым запуском бота выполните `logic.py`, чтобы создать таблицы и заполнить справочники значениями по умолчанию:

```bash
python logic.py
```

Будут созданы таблицы `projects`, `skills`, `project_skills`, `status`, а также добавлены:

- навыки: `Python`, `SQL`, `API`, `Telegram`
- статусы:
  - На этапе проектирования
  - В процессе разработки
  - Разработан. Готов к использованию.
  - Обновлен
  - Завершен. Не поддерживается

## Запуск

```bash
python main.py
```

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и список команд |
| `/info` | Список доступных команд |
| `/new_project` | Добавить проект: название → ссылка → статус |
| `/skills` | Добавить навык выбранному проекту |
| `/projects` | Список проектов с inline-кнопками для просмотра информации |
| `/update_projects` | Изменить поле проекта (имя, описание, ссылка, статус) |
| `/delete` | Удалить проект |

Также при вводе имени существующего проекта бот выводит информацию о нём.

### Формат вывода информации о проекте

```text
Project name: ...
Description: ...
Link: ...
Status: ...
Skills: ...
```

Если навыки не добавлены — выводится `Навыки пока не добавлены`.

## Структура базы данных

| Таблица | Поля |
|---|---|
| `projects` | `project_id`, `user_id`, `project_name`, `description`, `url`, `status_id` |
| `skills` | `skill_id`, `skill_name` |
| `project_skills` | `project_id`, `skill_id` |
| `status` | `status_id`, `status_name` |

## Класс `DB_Manager`

Класс из `logic.py` для работы с базой данных.

| Метод | Описание |
|---|---|
| `create_tables()` | Создаёт таблицы `projects`, `skills`, `project_skills`, `status` |
| `default_insert()` | Заполняет `skills` и `status` значениями по умолчанию |
| `insert_project(data)` | Добавляет проект |
| `insert_skill(user_id, project_name, skill)` | Привязывает навык к проекту пользователя |
| `get_statuses()` | Возвращает список статусов |
| `get_status_id(status_name)` | Возвращает ID статуса по имени |
| `get_projects(user_id)` | Возвращает проекты пользователя |
| `get_project_id(project_name, user_id)` | Возвращает ID проекта |
| `get_skills()` | Возвращает список навыков |
| `get_project_skills(project_name)` | Возвращает навыки проекта строкой через запятую |
| `get_project_info(user_id, project_name)` | Возвращает имя, описание, ссылку и статус проекта |
| `update_projects(param, data)` | Обновляет указанное поле проекта |
| `delete_project(user_id, project_id)` | Удаляет проект |
| `delete_skill(project_id, skill_id)` | Удаляет навык |
